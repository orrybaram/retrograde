# Retrograde

The solar system is a single powered-down machine, the **Titan**. The player, a scrapper, is nudged by its leftover **Automatons** into switching it back on, one planet at a time.

Full vocabulary, definitions and relationships: **`docs/GLOSSARY.md`**. Read the entry before naming anything in code or dialogue.

## Never break these

- Nothing is imprisoned. The Titan was switched off; the player only ever restores (docs/adr/0001).
- Every Automaton is the same mind in pieces that don't know about each other; none of them lies (docs/adr/0008).
- Nothing is named before the player reaches it: an unreached thing is **Unidentified**, and the **Log** has no row for it (docs/adr/0002, docs/adr/0003).
- Nothing is bought: the ship is upgraded only by **Components** found in the world (docs/adr/0007). **Stores** pay for repairs, fuel and Gates, never parts.
- **Freight** is flown, never stowed, and never lost (docs/adr/0012).
- Nothing goes backwards: no Module goes offline, no Record is taken away.
